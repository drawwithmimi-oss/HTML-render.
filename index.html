Quick start

  1. Tap Choose HTML file, pick your HTML from Files (works with files in iCloud Drive, Proton Drive, On My iPhone, etc.).
  2. Once loaded, tap Run app to launch it.
  3. Optional: turn on Auto-run so the app opens automatically next time.
  4. Optional: in DuckDuckGo or Safari, use Add to Home Screen to make this page a one-tap shortcut.

What stays private

The HTML file you load goes into your browser's local storage on this device. This page (the renderer) is the only thing on the internet. The app you load and any data it generates stay on your phone.

If something breaks

Tap Clear cache to wipe the loaded app and start fresh. This also clears any data the app stored under this page's domain.
